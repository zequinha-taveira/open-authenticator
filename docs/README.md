# Open Authenticator Framework — Documentation

Documentação pública do framework universal de autenticadores de segurança.

## Documentos

- [Arquitetura](architecture.md) — fronteiras entre protocolo, transporte, ambiente seguro e firmware.
- [Desenvolvimento](development.md) — setup, testes e fluxo de contribuição.
- [Forks de terceiros](forks.md) — como substituir componentes e adaptar o framework ao próprio hardware.

- [Testes](testing.md) — Virtual Hardware, CTAP2 Simulator, vetores e interoperabilidade.

## Status

Este diretório descreve a arquitetura inicial e não constitui uma certificação FIDO, Common Criteria ou avaliação independente de segurança.
